# RecordatoriosApp — Actividad 1

Proyecto inicial Android con Kotlin, Jetpack Compose y Material 3.

## Cómo abrirlo
1. Descomprimí el ZIP.
2. Abrí Android Studio y seleccioná **Open**.
3. Elegí la carpeta `RecordatoriosApp`.
4. Esperá a que termine la sincronización de Gradle.
5. En SDK Manager, instalá Android SDK Platform 35 si no está instalada.
6. En Device Manager, creá e iniciá un emulador.
7. Presioná Run ▶ para ejecutar la app.

## Qué incluye
- `Recordatorio`: data class inmutable con campos opcionales.
- `Categoria` y `Prioridad`: enums.
- `Estado`: sealed class.
- `List`: lista simulada de recordatorios.
- `Set`: categorías únicas.
- `Map`: colores por categoría.
- Filtros por todos, pendientes y prioridad alta.
- Interfaz Compose con Material 3.

## Antes de entregar
La app debe ejecutarse en tu Android Studio. Tomá capturas reales de la pantalla, la app abierta en el emulador y la estructura del proyecto. Añadí tu nombre y apellido y el enlace real de tu repositorio al PDF.
